# 🌸 Niwi Nails — Luxury Aesthetic Nail Art Studio Landing Page

Website landing page modern, minimalis, dan elegan yang dirancang khusus untuk bisnis **Niwi Nail Studio & Atelier**, menargetkan audiens wanita muda dengan nuansa estetika pastel yang mewah (*soft pink, nude beige, ivory white, dan rose gold*).

Dibuat dengan kode bersih menggunakan **HTML5 semantik**, **Tailwind CSS**, **Lucide Icons**, dan **Vanilla JavaScript** tanpa dependensi rumit (bisa langsung dibuka di browser tanpa perlu setup Node.js/build step).
